Tools

Built-in: look

look({reason, motion}) runs in the worker. A single look reads the latest frame; motion mode uses a short recent burst. Raw video is never fire-hosed into the model.

Client tools

tools: {
  saveTicket: {
    description: "Save the support ticket",
    parameters: { subject: "string", priority: "low | high" },
    handler: async (args) => api.save(args),
  }
}

Only the schema crosses the session API. The handler remains in the developer page. Calls and results travel over the room data channel and time out after 15 seconds.
