Configuration

OptionMeaning
sessionYour server-side session proxy URL. Required.
promptAgent behavior and workflow. Required.
visionPublish camera and enable the built-in look tool. Default false.
voiceOptional model, speaker, and description.
toolsBrowser handlers with descriptions and simple parameter schemas.
optionsSampling overrides: max_fps ≤5, image_max_side ≤1280, JPEG quality, burst count ≤12, burst window, frames/min ≤120.

Callbacks

onState receives connecting, live, reconnecting, ended, or error. onEvent receives session, camera, transcript, and tool events. onError receives actionable errors.
