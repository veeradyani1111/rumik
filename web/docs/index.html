One key. A prompt. Your tools.

Rumik Agent is a browser SDK backed by a server-side voice and vision pipeline. Upstream secrets never enter the browser.

Quickstart

  1. Get a platform key from the platform home page.
  2. Keep it on your server and proxy /session to the broker.
  3. Mount the agent.
import { RumikAgent } from "/sdk/rumik-agent.js";

const agent = RumikAgent.create({
  session: "/session",
  vision: true,
  prompt: "You are a warm, concise assistant.",
});
await agent.mount("#agent");

A platform key is a secret. Never embed it in client JavaScript. The browser receives only a short-lived, room-scoped LiveKit token.
