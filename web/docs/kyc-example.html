KYC is configuration

The applicant enters their name, date of birth and PAN number before KYC. The model reads those values from the card photo, and browser code compares them with the entered details without speaking the values aloud. Matching details unlock the hologram and liveness checks. The client tool persists the structured result through the developer's server.

const config = createKycConfig({
  expected: { name: "Veer Adyani", dob: "2000-08-30", pan: "ABCPD1234E" },
  onResult: renderResult,
});
const agent = RumikAgent.create(config);
await agent.mount("#agent");

The demo's liveness is heuristic and defeatable. Production KYC needs authoritative PAN verification and a dedicated liveness system.
